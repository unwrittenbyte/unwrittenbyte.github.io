Speed Limiter

A shared bandwidth cap for eligible Chrome download traffic, with real-time controls and a local Windows companion.

System requirements

  • Windows 11 x64 (tested); Windows 10 x64 (not yet verified).
  • Google Chrome 120 or newer.
  • Both the extension and companion; no Python installation required.

Installation

  1. Once available, install Speed Limiter from the Chrome Web Store. Advanced users can follow the repository build instructions for development testing.
  2. Download the matching companion from the official GitHub release. Verify the checksum, close Chrome completely, and run the installer for your Windows account if your security settings permit.
  3. Reopen Chrome and select Check Windows companion in the extension.
  4. Read and accept the local proxy disclosure, connect, choose your desired download speed and enable limiting.

Using Speed Limiter

The speed cap is shared by eligible downstream connections routed through the proxy. Change the cap while a proxied download is running. Switching bandwidth limiting OFF removes the cap but keeps the local proxy connected. Use Disconnect proxy to restore prior proxy settings and stop the engine.

Downloads begun before the proxy connected may bypass it; restart those downloads once connected. Local destinations, incognito, UDP/WebRTC, other apps and some browser services are not covered. Chrome may fall back to a direct connection. This is not a VPN or firewall.

VPN compatibility

Experimental VPN compatibility is disabled by default. If a trusted VPN or DNS filter uses supported synthetic DNS addresses, disconnect the local proxy and reconnect with VPN compatibility enabled. The indicator shows the proxy preference, not whether a VPN is connected. Keep required VPN protection active. If connectivity fails, disconnect the local proxy and compare. Do not rely on Speed Limiter to enforce VPN routing.

Verify the installer

On Windows, open PowerShell in the folder containing the downloaded installer and run:

Get-FileHash .\SpeedLimiter-Setup.exe -Algorithm SHA256

Compare the result with SHA256SUMS.txt from the official release. Matching hashes confirm that your downloaded installer matches the officially published file.

Uninstallation

  1. Click Disconnect proxy in the extension, then remove the extension from Chrome.
  2. Close Chrome completely.
  3. In Windows Settings → Apps, uninstall Speed Limiter Companion.
