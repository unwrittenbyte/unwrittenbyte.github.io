Scope

Effective 24 November 2026. This policy describes Speed Limiter for Google Chrome and its required Windows companion, published by Unwritten Byte, and this project website. This policy covers extension versions 1.0.6 and 1.0.6.1, and Windows companion version 1.0.6.

Information processed

When explicitly connected, the extension routes eligible HTTP and HTTPS traffic through a local proxy on your computer. This includes unlimited mode, when bandwidth limiting is OFF but the proxy remains connected. HTTP destination URLs, request and response headers and content, HTTPS destination hostnames and ports, and encrypted TLS traffic are processed in memory as needed to relay traffic and measure downstream bytes. The proxy does not decrypt HTTPS, install interception certificates or intentionally retain browsing history.

The companion checks local Windows process identifiers and executable paths to verify the Chrome process owning a local connection. If that check cannot authenticate the connection, the extension supplies a randomly generated proxy credential to matching local proxy authentication challenges; it does not retrieve website login credentials. Temporary request identifiers prevent repeated authentication attempts.

Speed, units, cap and connection preferences, VPN compatibility preference and acknowledgment are saved in Chrome local extension storage. Aggregate traffic and diagnostic counters and session credentials are held in companion memory and discarded when the engine stops. The installer stores the companion executable and native messaging manifest in your Windows profile and registers the host locally.

Purpose and retention

Local processing is used to apply bandwidth limits, connect to the companion, display its status and restore networking. After consent, the proxy may reconnect when Chrome restarts if left connected. Turn off limiting to remove the cap, or select Disconnect proxy to stop the engine and restore prior settings. Removing the extension and uninstalling the companion removes their local settings and program files. Chrome and Windows may separately retain ordinary history, download records and diagnostics.

Transmission and sharing

Ordinary network requests are sent to the destinations you choose, not a developer-operated traffic relay. The software does not transmit browsing logs, usage analytics, crash reports, account information or identifiers to Unwritten Byte or advertising partners. It does not sell personal information or use browsing activity for advertising, credit or unrelated purposes. No account is required.

Website operators, DNS resolvers, your internet provider, VPN provider if applicable, and the browser may separately handle network data under their own policies.

Security and limitations

The companion uses a loopback-only listener with a random port, Windows connection ownership checks, fallback session credentials, and a native host manifest restricted to the authorized extension ID. HTTP traffic is not inherently encrypted; the proxy does not add or remove encryption. The default destination filter blocks private and reserved IP ranges.

Optional experimental VPN compatibility permits DNS-resolved web destinations in 198.18.0.0/15 and address 192.0.0.88 for google.com and its subdomains, for trusted VPN or DNS-filter use. Google names prefer IPv4 OS DNS resolution in this mode. The setting does not verify VPN ownership of addresses or change DNS or VPN settings. Diagnostic counters contain no hostnames. These measures do not guarantee complete security; Speed Limiter is not a VPN or firewall.

Website and downloads

This static website does not include developer-operated tracking scripts, analytics, cookies or forms. It is hosted on GitHub Pages, which logs and stores visitor IP addresses for security purposes, even when visitors are signed out. GitHub also hosts the source repository, release downloads and issue reporting. GitHub handles service data according to its Privacy Statement. See also GitHub Pages data collection.

External services have their own data handling practices. This site does not embed third-party resources.

Privacy requests and contact

Depending on applicable law, you may have rights to access, correct, erase or restrict processing, object to processing and complain to your data protection authority. Unwritten Byte does not receive extension browsing records, and therefore normally has no such records to provide or delete.

For general questions or to request a private contact channel for a privacy inquiry, use the project issue tracker. Do not include personal or sensitive information in a public issue. For suspected security vulnerabilities, use private vulnerability reporting. Information you voluntarily submit is used to address your inquiry; GitHub's own retention and privacy practices apply to submissions hosted there.

Changes to this policy

If data practices change, this policy will be updated, with notices or consent where required. Current source and release information are available in the project repository.
