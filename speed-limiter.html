Unsigned installer

The installer is currently unsigned, so Windows may display a security warning or prevent installation. Keep your security protections enabled. The source code, build instructions, build log and SHA-256 checksum are publicly available for verification. Checking the installer checksum before running it is recommended for additional assurance, but is not a required installation step. Learn how to verify the installer. No Windows code-signing certificate is used to authenticate this release.

System requirements

  • Windows 11 x64 (tested); Windows 10 x64 (not yet verified).
  • Google Chrome 120 or newer.
  • Both the extension and companion; no Python installation required.

Installation

  1. Install Speed Limiter from the Chrome Web Store. The extension opens a welcome and setup page on first installation. Advanced users can follow the repository build instructions for development testing.
  2. Click Download Windows companion in the extension, acknowledge the installation instructions, and download the installer from the download section above.
  3. Close Chrome completely and run the installer for your Windows account, subject to your Windows security settings.
  4. Reopen Chrome and open Speed Limiter. It automatically checks for a compatible companion. Select Check installation if prompted.
  5. Read and accept the local proxy disclosure, connect, choose your desired download speed and enable limiting.

Companion not detected?

Make sure you installed the official Windows companion v1.0.6 and are using the official extension or an authorized development build. Close Chrome completely, reopen it and select Check installation. If needed, reinstall the official companion with Chrome closed. Do not modify Chrome security settings to bypass connection errors.

Using Speed Limiter

The speed cap is shared by eligible downstream connections routed through the proxy. Change the cap while a proxied download is running. Switching bandwidth limiting OFF removes the cap but keeps the local proxy connected. Use Disconnect proxy to restore prior proxy settings and stop the engine.

Downloads begun before the proxy connected may bypass it; restart those downloads once connected. Local destinations, incognito, UDP/WebRTC, other apps and some browser services are not covered. Chrome may fall back to a direct connection. This is not a VPN or firewall.

VPN compatibility

Experimental VPN compatibility is disabled by default. If a trusted VPN or DNS filter uses supported synthetic DNS addresses, disconnect the local proxy and reconnect with VPN compatibility enabled. The indicator shows the proxy preference, not whether a VPN is connected. Keep required VPN protection active. If connectivity fails, disconnect the local proxy and compare. Do not rely on Speed Limiter to enforce VPN routing.

Verify the installer

Optional security check (recommended). This is not required by the installer.

On Windows, open PowerShell in the folder containing the downloaded installer and run:

Get-FileHash .\SpeedLimiter-Setup.exe -Algorithm SHA256

Compare the result with SHA256SUMS.txt from the official release. Matching hashes confirm that your downloaded installer matches the officially published file.

Uninstallation

  1. Click Disconnect proxy in the extension, then remove the extension from Chrome.
  2. Close Chrome completely.
  3. In Windows Settings → Apps, uninstall Speed Limiter Companion.
